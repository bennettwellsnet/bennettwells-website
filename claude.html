AI Proficiency

I use AI every day: Claude and Microsoft Copilot at work for automation and for analyzing risk and compliance data, and Grok on my own time for this website and its demos. Knowing which tool fits the job, and checking what it produces, is part of the skill.

Toolkit

Three Tools, Three Jobs

Each assistant has a different strength, so I use them for different kinds of work rather than defaulting to one.

Work
⚙

Claude

My main tool for automating work tasks: scripting, documentation, and config review. I also use it to analyze risk and compliance data, turning raw findings and exports into clear summaries and next steps.

Microsoft 365
💼

Microsoft Copilot

Sending users targeted reminders about patching and other actions they need to take, so follow-up happens without manual chasing. I also use it alongside Claude to analyze risk and compliance data inside Microsoft 365.

Personal
🚀

Grok

My personal tool for building this website and several of the demos on it, from small calculators to live data dashboards. A good way to try new ideas outside of work.

Approach

Workflows

Claude at Work

I integrate Claude across day-to-day IT operations: drafting documentation, building automation scripts, reviewing security configs, and accelerating work that used to take hours. Below are the areas where it's made the biggest impact.

Infrastructure
⚙

Configuration Documentation

Using Claude to generate and maintain infrastructure documentation (firewall rules, network topology, Azure policy configs) directly from raw config exports, keeping docs in sync with reality.

Security
🔒

Security Policy Review

Feeding security policies and audit findings into Claude to identify gaps, plain-language explanations for stakeholders, and draft remediation steps, accelerating SOC 2 and HIPAA compliance work.

Automation
💻

PowerShell & Script Generation

Generating and debugging PowerShell, Bash, and Python scripts for endpoint management, Azure automation, and scheduled maintenance tasks, cutting scripting time significantly.

Operations
📋

Runbook & SOP Authoring

Drafting and refining runbooks, incident response procedures, and SOPs from bullet-point notes, producing polished operational documents without the usual back-and-forth revision cycles.

Vendor Management
📜

Contract & RFP Analysis

Using Claude to parse vendor contracts, surface non-standard terms, and draft RFP evaluation criteria, helping make faster and better-informed procurement decisions.

Development
🌐

Built and iterated on bennettwells.net using Claude Code, from initial design to ongoing updates, showing how AI-assisted development fits into a modern IT toolkit.
